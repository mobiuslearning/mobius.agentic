## Prompt

```text
请帮助我理解这个代码库，但先不要修改任何文件。

先给出一张项目地图：入口、核心模块、数据流、外部依赖与测试位置。然后选择一条最能代表系统行为的用户路径，从请求进入开始，一步步追踪到最终输出，并引用具体文件。

解释时假设我熟悉编程，但不了解这个项目。优先说明项目特有的设计决定，不要讲通用语法。遇到无法从代码确认的内容，请标为“待验证”。最后列出最适合继续阅读的 5 个文件及阅读顺序。
```
